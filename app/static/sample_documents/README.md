# Documentos de Muestra

Esta carpeta contiene documentos de muestra para demostración en Vercel.

## Archivos incluidos:
- `certificacion_iso9001.pdf` - Certificación ISO 9001 de ejemplo
- `certificacion_haccp.pdf` - Certificación HACCP de ejemplo
- `auditoria_interna.pdf` - Auditoría interna de ejemplo
- `politica_calidad.pdf` - Política de calidad de ejemplo

## Uso:
Estos archivos se usan cuando `USE_SAMPLE_DOCUMENTS=true` en las variables de entorno.
En Vercel, el sistema automáticamente usará estos archivos estáticos para la vista previa.
